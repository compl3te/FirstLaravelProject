Проект предназначен для получения, анализа и сохранения регистрационных данных IP-адресов. Приложение запрашивает информацию через сторонние API и сохраняет структурированные данные в базу данных.

## Текущий статус проекта
* **Backend:** Практически полностью готов. Логика парсинга и сохранения данных работает.
* **Frontend:** Реализован в базовом виде (шаблоны без использования JavaScript). 
* **Отображение данных:** Вывод результатов на фронтенд пока не настроен. На текущем этапе данные успешно собираются и сохраняются в базу данных.

## Структура базы данных
Собранные данные сохраняются в БД в виде записей со следующими полями:
| Поле | Описание |
| :--- | :--- |
| `id` | Уникальный идентификатор записи |
| `ip` | Исследуемый IP-адрес |
| `country` | Страна расположения (получено через ipwho) |
| `organization` | Организация-владелец (получено через ipwho) |
| `netname` | Имя сети (получено через rdap) |
| `ip_range` | Диапазон IP-адресов (получено через rdap) |

## Используемые API
Для получения данных интегрированы два внешних сервиса:
1. **ipwho** — используется для получения базовой геолокации (страна) и информации об организации.
2. **RDAP** (Registration Data Access Protocol) — используется для получения глубоких регистрационных данных (netname, ip_range).

## Установка и запуск
Для локальной разработки и тестирования использовался **MAMP**.

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <ссылка_на_репозиторий>
   cd <название_папки>
2. Установите зависимости
   ```bash
   composer install
3. Настройте файл .env
4. Запустите миграции базы данных
   ```bash
   php artisan migrate
5. Запуск сервера
   ```bash
   php artisan serve
